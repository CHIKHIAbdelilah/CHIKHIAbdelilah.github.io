# Portfolio Abdelilah Chikhi

## Mise en ligne sur GitHub Pages

1. Décompresser le ZIP.
2. Ouvrir le dépôt `CHIKHIAbdelilah.github.io` sur GitHub.
3. Remplacer les fichiers du dépôt par le contenu de ce dossier.
4. Conserver le fichier `CNAME` contenant `chikhiabdelilah.com`.
5. Valider les changements sur la branche `main`.

GitHub Pages republiera automatiquement le site. La mise à jour peut demander quelques minutes.

## Personnalisation utile

Le bouton de contact pointe actuellement vers le profil GitHub. Pour afficher une adresse professionnelle, remplacer le lien GitHub de la section `contact` dans `index.html` par un lien `mailto:`.
